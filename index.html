ProtVista

An embeddable protein feature viewer web component (<protvista-uniprot>). Point it at a UniProt accession, or drive it with your own declarative configuration and data.

Try it

Configuration playground
Edit a YAML/JSON config with live validation and see the viewer re-render as you type. Share your setup with a link.

The default UniProt viewer. Swap proteins with ?accession=.
