# Known consumers of ProtVista (public adoption baseline)

## Scope and method

**Recorded here.** Publicly-acknowledged use of ProtVista or the underlying `@nightingale-elements/*` tracks, where the evidence is already public e.g. paper, release-notes, or GitHub repository.

**How the audit was conducted.** Peer-reviewed publications and public release notes; public GitHub repositories that fork the ProtVista codebase or declare it as a dependency; live-DOM inspection of public web pages for the `<protvista-uniprot>` element.
